### 1단계: 업무 규칙 문장 작성

### 1단계: 업무 규칙 문장 작성

1. 회원은 회원가입을 할 수 있다.
2. 회원은 가입한 계정으로 로그인할 수 있다.

3. 로그인한 회원은 게시글을 작성할 수 있다.
4. 로그인한 회원은 본인이 작성한 게시글만 수정할 수 있다.
5. 로그인한 회원은 본인이 작성한 게시글만 삭제할 수 있다.
6. 게시글에는 작성시간이 기록된다.

7. 비회원도 게시글 목록과 상세 내용을 조회할 수 있다.
8. 비회원이 게시글을 조회해도 조회수는 증가하지 않는다.
9. 로그인한 회원이 게시글 상세 내용을 조회하면 조회수가 증가한다.
10. 로그인한 회원이 본인 게시글을 조회해도 조회수가 증가한다.
11. 로그인한 회원이 같은 게시글을 여러 번 조회해도 조회수는 중복 증가한다.

12. 로그인한 회원은 게시글에 댓글을 작성할 수 있다.
13. 로그인한 회원은 본인이 작성한 댓글만 수정할 수 있다.
14. 로그인한 회원은 본인이 작성한 댓글만 삭제할 수 있다.
15. 사용자는 게시글에 작성된 댓글 목록을 조회할 수 있다.

16. 로그인한 회원은 게시글에 좋아요를 누를 수 있다.
17. 로그인한 회원은 댓글에 좋아요를 누를 수 있다.
18. 한 회원은 같은 게시글에 좋아요를 한 번만 누를 수 있다.
19. 한 회원은 같은 댓글에 좋아요를 한 번만 누를 수 있다.
20. 로그인한 회원은 본인이 누른 좋아요를 취소할 수 있다.

21. 로그인한 회원은 게시글 작성 시 이미지 파일을 첨부할 수 있다.
22. 하나의 게시글에는 여러 개의 이미지 파일을 첨부할 수 있다.

23. 카테고리는 시스템에 미리 존재한다고 가정한다.
24. 로그인한 회원은 게시글 작성 시 하나 이상의 카테고리를 선택할 수 있다.
25. 회원은 카테고리를 생성, 수정, 삭제할 수 없다.

26. 사용자는 게시글 제목으로 검색할 수 있다.
27. 사용자는 게시글 본문으로 검색할 수 있다.
28. 사용자는 카테고리 기준으로 게시글을 검색할 수 있다.

### 3단계: 한 행의 의미 작성

1. 회원
- 한 행의 의미: 회원의 한 행은 커뮤니티 게시판에 가입한 한 명의 사용자이다.

2. 게시글
- 한 행의 의미: 게시글의 한 행은 한 회원이 작성한 하나의 게시글이다.

3. 댓글
- 한 행의 의미: 댓글의 한 행은 한 회원이 하나의 게시글에 작성한 하나의 댓글이다.

4. 좋아요
- 한 행의 의미: 좋아요의 한 행은 한 회원이 하나의 게시글 또는 하나의 댓글에 좋아요를 누른 하나의 기록이다.

5. 이미지 파일
- 한 행의 의미: 이미지 파일의 한 행은 하나의 게시글에 첨부된 하나의 이미지 파일 정보이다.

6. 카테고리
- 한 행의 의미: 카테고리의 한 행은 게시글을 분류하기 위해 시스템에 미리 존재하는 하나의 분류 항목이다.

### 4단계: 관계 수량 정리

1. 회원 ↔ 게시글
- 관계: 1:N

2. 회원 ↔ 댓글
- 관계: 1:N

3. 게시글 ↔ 댓글
- 관계: 1:N

4. 회원 ↔ 게시글 좋아요
- 회원 1명은 게시글 좋아요를 여러 개 만들 수 있다.
- 게시글 좋아요 1개는 회원 1명에게 속한다.
- 관계: 1:N

5. 게시글 ↔ 게시글 좋아요
- 게시글 1개는 게시글 좋아요를 여러 개 받을 수 있다.
- 게시글 좋아요 1개는 게시글 1개에 속한다.
- 관계: 1:N

6. 회원 ↔ 댓글 좋아요
- 관계: 1:N

7. 댓글 ↔ 댓글 좋아요
- 관계: 1:N

8. 게시글 ↔ 이미지 파일
- 관계: 1:N

9. 게시글 ↔ 카테고리
- 게시글 1개는 여러 카테고리를 가질 수 있다.
- 카테고리 1개에는 여러 게시글이 속할 수 있다.
- 관계: N:M

### 7단계: 식별자 정하기

1. 회원
- 대표 식별자: 회원 ID
- 중복되면 안 되는 값: 이메일, 닉네임

2. 게시글
- 대표 식별자: 게시글 ID
- 중복되면 안 되는 값: 없음

3. 댓글
- 대표 식별자: 댓글 ID
- 중복되면 안 되는 값: 없음

4. 카테고리
- 대표 식별자: 카테고리 ID
- 중복되면 안 되는 값: 카테고리명

5. 게시글 좋아요
- 대표 식별자: 게시글 좋아요 ID
- 중복되면 안 되는 조합: 회원 ID + 게시글 ID

6. 댓글 좋아요
- 대표 식별자: 댓글 좋아요 ID
- 중복되면 안 되는 조합: 회원 ID + 댓글 ID

7. 이미지 파일
- 대표 식별자: 이미지 파일 ID
- 중복되면 안 되는 값: 저장 파일명 또는 파일 경로

8. 게시글-카테고리 연결 기록
- 대표 식별자: 게시글 ID + 카테고리 ID 조합
- 중복되면 안 되는 조합: 게시글 ID + 카테고리 ID

### 8단계: 관계 연결하기

1. 회원
- 다른 엔터티와 연결되는 ID: 없음

2. 게시글
- 다른 엔터티와 연결되는 ID: 회원 ID

3. 댓글
- 다른 엔터티와 연결되는 ID: 회원 ID, 게시글 ID

4. 카테고리
- 다른 엔터티와 연결되는 ID: 없음

5. 게시글 좋아요
- 다른 엔터티와 연결되는 ID: 회원 ID, 게시글 ID

6. 댓글 좋아요
- 다른 엔터티와 연결되는 ID: 회원 ID, 댓글 ID

7. 이미지 파일
- 다른 엔터티와 연결되는 ID: 게시글 ID

8. 게시글-카테고리 연결 기록
- 다른 엔터티와 연결되는 ID: 게시글 ID, 카테고리 ID

### 9단계: 테이블 초안 작성

1. 회원
- 대표 식별자: 회원 ID
- 연결 ID: 없음
- 일반 속성: 이메일, 비밀번호 해시, 닉네임, 가입시간

2. 게시글
- 대표 식별자: 게시글 ID
- 연결 ID: 회원 ID
- 일반 속성: 게시글 제목, 게시글 본문, 게시글 작성시간, 게시글 수정시간, 조회수

3. 댓글
- 대표 식별자: 댓글 ID
- 연결 ID: 게시글 ID, 회원 ID
- 일반 속성: 댓글 본문, 댓글 작성시간, 댓글 수정시간

4. 카테고리
- 대표 식별자: 카테고리 ID
- 연결 ID: 없음
- 일반 속성: 카테고리명

5. 게시글 좋아요
- 대표 식별자: 게시글 좋아요 ID
- 연결 ID: 회원 ID, 게시글 ID
- 일반 속성: 좋아요 누른 시간
- 중복되면 안 되는 조합: 회원 ID + 게시글 ID

6. 댓글 좋아요
- 대표 식별자: 댓글 좋아요 ID
- 연결 ID: 회원 ID, 댓글 ID
- 일반 속성: 좋아요 누른 시간
- 중복되면 안 되는 조합: 회원 ID + 댓글 ID

7. 이미지 파일
- 대표 식별자: 이미지 파일 ID
- 연결 ID: 게시글 ID
- 일반 속성: 원본 파일명, 저장 파일명, 파일 경로, 파일 크기, 파일 타입, 첨부 시간

8. 게시글-카테고리 연결 기록
- 대표 식별자: 게시글 ID + 카테고리 ID
- 연결 ID: 게시글 ID, 카테고리 ID
- 일반 속성: 없음
- 중복되면 안 되는 조합: 게시글 ID + 카테고리 ID



### PostgreSQL이란?
객체 관계형 데이터베이스 시스템으로, SQL 기반.

설치
brew install postgresql@18

실행
brew services start postgresql@18

접속
psql postgres

생성
CREATE USER board_user WITH PASSWORD 'board_pass';
CREATE DATABASE community_board OWNER board_user;

DB 접속
psql -U board_user -d community_board -h localhost
