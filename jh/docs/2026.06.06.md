Nest.js

NestJS는 Express/Fastify 위에서 동작하는 Node.js 백엔드 프레임워크이며, TypeScript와 클래스 기반 구조를 사용해서 서버 프로젝트를 더 테스트하기 쉽고, 확장 가능하고, 유지보수하기 좋게 만들어주는 아키텍처 중심 프레임워크입니다.

Express란?
Node.js에서 웹 서버/API 서버를 쉽게 만들 수 있게 해주는 백엔드 웹 프레임 워크

Express가 해주는 대표적인 일
- 라우팅 처리
- 요청과 응답 객체 제공
- JSON body 파싱
- 미들웨어 연결
- 정적 파일 제공
- 에러 처리 구조 제공

Fastify란?
Node.js 에서 웹 서버/API 서버를 만들기 위한 백엔드 웹 프레임워크

Fastify 특징
- 빠른 성능
- 낮은 오버헤드
- JSON Schema 기반 요청/응답 검증
- 플러그인 구조
- TypeScript 지원

npm i -g @nestjs/cli
nest new project-name

npm start 명령어를 통해 실행 시켜 설치가 제대로 되었는지 확인 할 수 있다.

app.controller.ts: 단일 경로를 가진 기본 컨트롤러
app.controller.spec.ts: 컨트롤러에 대한 단위 테스트
app.module.ts: 애플리케이션의 루트 모듈
app.service.ts: 단일 메서드를 가진 기본 서비스
main.ts: NestFactory Nest 애플리케이션 인스턴스를 생성하는 핵심 함수를 사용하는 애플리케이션의 진입 파일입니다.
