## **2. 핵심 내용**

---

React 애플리케이션은 `index.html`의 `#root` 영역을 기준으로 실행된다. `script` 태그를 통해 `main.tsx`가 실행되고, `main.tsx`는 `#root` DOM을 찾아 최상위 컴포넌트인 `App`을 렌더링한다. 이 구조를 기반으로 하나의 HTML 문서 안에서 여러 화면을 전환하는 SPA 구조를 만들 수 있다.

SPA는 처음 접속할 때 필요한 HTML, JavaScript, CSS를 로드한 뒤, 화면 이동 시 서버에서 새로운 HTML 문서를 다시 받아오지 않고 클라이언트에서 필요한 컴포넌트만 교체해 화면을 다시 그리는 방식이다. 이 때문에 페이지 전체가 새로고침되지 않아 화면 전환이 빠르고 자연스럽게 느껴진다.

다만 SPA는 초기 접속 시 JavaScript 번들 등 필요한 리소스를 먼저 로드해야 하므로 첫 로딩 속도가 느려질 수 있다. 이를 개선하기 위해 코드 스플리팅, Lazy Loading, 캐싱, 번들 최적화 같은 성능 최적화 기법을 고려할 수 있다.

`App.tsx`는 전체 화면을 조립하고 라우팅을 관리하는 역할을 한다. 작은 규모의 프로젝트에서는 `pages`, `components`, `styles`, `assets` 정도로 폴더를 나누는 방식이 적절하다. 페이지 단위 화면은 `pages`에 두고, 재사용 가능한 UI는 `components`에 둔다.

CSS 파일을 여러 개로 분리해도 일반 CSS는 전역으로 적용된다. 따라서 같은 class 이름이나 id 이름을 여러 파일에서 사용하면 의도하지 않은 스타일 충돌이 발생할 수 있다. 이를 줄이기 위해 `.header-title`, `.home-page-title`처럼 컴포넌트나 페이지 이름을 접두사로 붙여 작성하는 것이 좋다.

TypeScript에서는 props 타입을 명시하여 컴포넌트가 받을 수 있는 값을 제한할 수 있다. 예를 들어 버튼 컴포넌트의 `type`을 `"next" | "back"`으로 정의하면, 해당 prop에는 `"next"` 또는 `"back"`만 전달할 수 있다. 잘못된 문자열을 전달하면 실행 전에 TypeScript가 오류를 알려준다.

JSX는 JavaScript 안에서 HTML과 비슷한 구조를 작성할 수 있게 해주는 문법이다. React에서는 `class` 대신 `className`을 사용하고, JavaScript 값을 JSX 안에 넣을 때는 `{}`를 사용한다. 또한 여러 요소를 반환할 때는 하나의 부모 요소로 감싸야 한다.

React Router를 사용하면 SPA 안에서 URL에 따라 다른 컴포넌트를 렌더링할 수 있다. `BrowserRouter`는 라우팅 정보를 하위 컴포넌트에 제공하는 Provider 역할을 하며, `Routes`와 `Route`를 통해 경로별 페이지 컴포넌트를 연결한다.

## **3. 프로젝트 적용**

---

**프로젝트에 적용할 부분**

- React 프론트엔드 구조를 `pages`, `components`, `styles`, `assets` 기준으로 정리한다.
- 공통 UI 컴포넌트는 `components`에 두고, 페이지별 화면은 `pages`에 분리한다.
- CSS 클래스명은 컴포넌트 또는 페이지 이름을 접두사로 붙여 전역 충돌을 줄인다.
- 버튼 컴포넌트처럼 동작이 정해진 props는 TypeScript union type으로 제한한다.
- React Router를 사용해 URL별 페이지 이동 구조를 구성한다.

## **4. 팀 공유**

---

**팀원들에게 전달할 내용**

- SPA에서는 `index.html`이 직접 화면을 모두 그리는 것이 아니라, `main.tsx`가 `#root`에 React 앱을 마운트한다.
- 일반 CSS는 파일을 분리해도 전역으로 적용되므로 class 이름 충돌을 주의해야 한다.
- React Router를 사용할 때 `BrowserRouter`, `Routes`, `Route`, `Link`의 역할을 구분해야 한다.
- TypeScript의 `?`는 해당 prop이 없어도 된다는 의미이고, union type은 prop에 들어올 수 있는 값을 제한하는 데 사용할 수 있다.
- JSX는 HTML이 아니라 JavaScript 안에서 UI 구조를 표현하는 문법이며, 브라우저가 이해할 수 있도록 빌드 과정에서 JavaScript로 변환된다.
