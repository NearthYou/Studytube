image-gen 써서 미니멀하고 제품사진이 가득한 프리미엄 가구 쇼핑몰을 만들어줘. react, tailwind로 프론트엔드 구성하고, h18n으로 영어/한국어/중국어 지원하는데 영어가 디폴트, 타이틀영역같은거 큰 글씨 줄바뀜 억지스럽지 않게 잘 처리하고, db는 일단 Sql lite, 회원가입과 관리자 기능까지 필요한 기능을 전부 다 만들어줘. 그리고 상품 등록은 openai api key 사용해서 ai로 생성하고 검수해서 등록할 수 있게 해주고, 소스는 깃헙에 daeyeol-oai/atlier-next로 올려, 그리고 관리자 기능에 사이트 개선 하는 것 까지 넣어서 대충 자연어로 입력받으면 이슈에 항목 넣게 해줘. 그리고 triage 자동으로 걸어서 spec문서로 이슈를 구체 화할 수 있게 해주고, 그리고 프론트엔드의 모든 기능을 툴로 만들어서 realtime api 2로 쇼핑 도우미 에이전트가 작동하게 해줘. 그리고 tool 중에는 장기 기억과 에이전트를 위해 gpt-5.5를 호출하는 것도 만들어서 복잡한 요구에는 그 툴을 사용하게 해주고, 대화 히스토리에는 realtime api의 대화이력과 tool 이력들이 같이 들어가서 gpt-5.5 에이전트가 역으로 realtime 대화이력도 참조 할 수 있게 해줘. gpt-5.5에서는 agents sdk 써서 요청받은대로 인보이스 생성같은거 해서 pdf로 내려주고 이런거나 비교 분석 리포트같은거 만들 수 있겠네. 쇼핑도우미 에이전트는 개발자모드 토글 달아서 툴콜같은거 로그도 볼 수 있게 해주고. 그런데 결제모듈은 아직 미정이니깐 목업으로 ui만 만들고 결제버튼 누르면 결제 된 것처럼 하면 되. 아무튼 필요한 부분은 너가 잘 고민해 서 잘 정돈된 ui와 uX로 프리미엄 경험을 줄 수 있는 앱을 만들어줘.
