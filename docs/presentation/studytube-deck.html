Caption Translation Issue

긴 영상에서 한국어 AI 자막이 늦게 보이는 문제

원본 자막은 있었지만 전체 영상을 한 번에 번역하려 하면서 첫 화면에 필요한 한국어 자막이 제때 도착하지 않았습니다.

2,134 segments async timing playback window

Before 전체 번역

  • 긴 transcript 전체를 하나의 작업으로 처리
  • 번역 완료 전까지 source caption만 반복 반환
  • 사용자는 자막 생성 실패처럼 인식

After 3분 window

  • 현재 재생 구간의 세그먼트만 필터링
  • startSeconds/endSeconds로 작은 번역 요청
  • 번역된 window만 안전하게 병합
