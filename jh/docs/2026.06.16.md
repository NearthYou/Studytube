- SDK 란?
software development kit
API = 기능을 사용할 수 있는 규칙/주소
SDK = 그 API를 쉽게 쓰게 해주는 도구 모음

SDK는 특정 플랫폼이나 서비스를 내 코드에서 쉽게 사용하기 위해 제공되는 개발 도구 세트

### Codex 기능

#### Plan 모드

- 무슨 기능인가?
구현 전에 작업 계획을 먼저 세우는 모드

- 특징
바로 코드를 수정하지 않고, 작업 범위, 변경 파일 , 구현 순서, 테스트 기준을 정리함.

- 언제 사용하면 좋은가?
요구사항이 크거나 불명확할 때, 여러 파일이 함께 바뀔 때

Q. 왜 요구사항이 크거나 불명확할 때나 여러파일이 함께 바뀔 때 사용하면 좋은가? 여기에는 LLM의 한계가 존재하는 것인가?

A. Plan 모드가 더 똑똑하다가기 보다는, 큰 작업에서 LLM이 놓치기 쉬운 범위, 맥락, 변경 영향, 검증 지점을 먼저 구조화해 오류 누적을 줄일 수 있다.

Q. plan도 LLM이 만들거라면, 첫 번째 프롬프트 때 해당 프롬프트를 가지고 plan을 만들고 해당 plan을 가지고 작업하면 되는거 아닌가? 왜 유저가 한 번 plan을 만드는 과정을 거쳐야 하는 것인가?

A. Plan 모드는 LLM이 내부적으로 세우는 임시 계획을 명시적인 작업 계획으로 외부화하는 기능이다. 
LLM은 첫 프롬프트만으로도 어느 정도 계획을 세울 수 있지만, 그 계획은 사용자가 검토하거나 수정하기 어렵고, 모호한 요구사항에 대한 잘못된 가정이 그대로 구현에 반영될 수 있다. 
Plan 모드를 사용하면 작업 범위, 맥락, 변경 영향, 구현 순서, 검증 기준을 먼저 확인할 수 있어 큰 작업에서 방향 착오와 누락을 줄일 수 있다.

- 기대할 수 있는 것
구현 전에 빠진 요구사항, 위험요소, 작업 순서를 확인할 수 있다. 불필요한 코드 수정과 방향 착오를 줄일 수 있다.
